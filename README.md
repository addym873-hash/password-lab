# Password Lab 🔐

A privacy-first password security analyzer built with HTML, CSS, and JavaScript.

## Live Demo

https://addym873-hash.github.io/password-lab/

## Project Purpose

I created this project to develop my programming and cybersecurity skills and explore how password length, predictability, and repeated patterns affect password security.

## Features

- Interactive password strength analyzer
- Common password detection
- Repeated character and pattern detection
- Educational security recommendations
- Random example-password generator
- Local, browser-based password analysis

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages
- Web Crypto API

## Privacy and Security

Password analysis takes place locally in the browser.

Testing confirmed that the analyzer works offline and that no network requests appeared while entering sample passwords or generating examples.

This project is an educational tool, not a professional security assessment or breach checker. Never enter real passwords.
